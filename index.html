Perguntas frequentes

Antes de colocar o Lumen na sua rotina.

O projeto está em desenvolvimento ativo. Transparência sobre limites e funcionamento faz parte da proposta.

Ainda tem dúvidas? Abra uma issue
O Lumen é realmente gratuito?

Sim. O projeto é open source, distribuído sob licença MIT, e não exige assinatura para usar as funcionalidades principais.

Preciso conectar minha conta bancária?

Não. Você pode importar arquivos como CSV e OFX ou cadastrar lançamentos manualmente, sempre revisando a prévia antes da confirmação.

O Lumen envia meus dados para a nuvem?

Não. O aplicativo foi desenhado para processar e armazenar dados financeiros localmente, sem sincronização forçada ou backend web.

Os dados já são criptografados pelo aplicativo?

Ainda não. O banco SQLite e os backups locais não possuem criptografia nativa pelo Lumen. A recomendação atual é proteger o computador com senha forte, criptografia de disco e backups seguros.

Em quais sistemas o Lumen funciona?

As versões publicadas atualmente são voltadas ao Windows. Consulte a página de releases para requisitos e novidades da versão mais recente.
